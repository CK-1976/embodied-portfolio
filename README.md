# 具身智能项目网站

这个目录是一个无需后端的静态网站。项目页、内容编辑页和投递版简历共用 `content.json`；图片、视频放在 `assets` 下。编辑页使用实际网页与简历模板实时预览草稿。公开源码中的姓名和邮箱使用占位内容；发布时 GitHub Actions 从私密密钥注入实际资料。公开网站包含实机录像与压缩后的仿真演示片段，工作区原始视频没有改动。

## 本地预览

在本目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

- 项目网站：`http://127.0.0.1:8000/`
- 内容编辑：`http://127.0.0.1:8000/editor.html`
- 投递版预览：`http://127.0.0.1:8000/resume.html`

不要直接双击 HTML 文件；浏览器对本地 JSON 文件有限制。

## 更新项目与媒体

1. 打开 [在线内容编辑页](https://ck-1976.github.io/embodied-portfolio/editor.html) 或本地的 `editor.html`。左侧选择首页、工作经历、能力或项目，右侧切换实际网页与简历预览。修改文字后预览会自动更新；在项目里可以分别编辑网站卡片、详细经历与 PDF 要点。
2. 在首页或项目的素材区域直接选择图片、MP4 视频，也可以拖入文件。素材立即进入当前浏览器草稿并显示在预览中。图片支持 JPG、PNG、WebP；单个文件不超过 80 MB，视频建议先压缩并添加封面。
3. 推荐点击“保存到本地项目目录”，选择这个仓库的根目录。浏览器会把去除姓名、邮箱等私密资料的 `content.json` 和新素材写到正确位置。支持该功能的浏览器会弹出目录授权。如果浏览器不支持，点击“下载发布包”，将 ZIP 解压到仓库根目录并覆盖 `content.json`。
4. 检查变更，然后提交并推送到 GitHub 的 `main` 分支。GitHub Actions 会自动生成投递版 PDF 并发布网站。若只修改了文字，也可用“仅下载内容 JSON”替换仓库里的同名文件。

草稿和新素材存放在当前浏览器，清除浏览器网站数据会丢失未导出的修改；请及时保存到本地项目目录或下载发布包。编辑页无法直接替访客改动 GitHub 仓库。草稿预览里的 PDF 按钮打开当前草稿的打印页；公开网站上的按钮下载已发布的 PDF。

姓名、缩写、邮箱和电话只在发布后的网页与 PDF 中显示，不写进公开源码或发布包。若要修改这些资料，在编辑页点击“复制私密资料”，前往仓库 **Settings → Secrets and variables → Actions** 更新 `PORTFOLIO_PRIVATE_PROFILE` 密钥，内容是编辑页复制的 JSON。不要把密钥内容贴进仓库文件、提交记录、Issue 或 Actions 日志。下次推送或手动运行发布工作流时，网页与 PDF 会使用新的资料。

需要在本机手动生成带真实姓名的 PDF 时，先把网站文件复制到 Git 忽略的 `_site` 目录，再执行 `python3 prepare_site.py --site _site --profile-file /你的路径/private-profile.json` 和 `python3 build_pdf.py --site _site`。这一步需要 Chrome 或 Chromium；若安装了匹配的 ChromeDriver，会优先使用它。PDF 包含当前勾选“纳入 PDF 简历”的项目。不要把生成的 PDF 提交到公开源码仓库。

编辑器里填写的电话会在发布后显示于网页和 PDF，但不会写进公开仓库的 `content.json`。当前版本公开两个邮箱，没有把原始简历中的电话放进网站。

## 通过 GitHub Pages 发布

公开源码仓库为 [CK-1976/embodied-portfolio](https://github.com/CK-1976/embodied-portfolio)，面试官访问[项目网站](https://ck-1976.github.io/embodied-portfolio/)即可。仓库的 GitHub Actions 工作流会在推送 `main` 分支后注入私密资料、生成最新 PDF 并发布网站。若密钥缺失或 PDF 生成失败，工作流会停止发布，避免网页与简历内容不一致。源码仓库及 Git 历史不包含姓名和邮箱；网页和 PDF 仍公开展示这些信息。

发布前请逐项确认个人资料、公司项目描述和媒体内容；GitHub Pages 页面是公开网页。`editor.html` 的草稿只保存在访问者自己的浏览器，访问者不能借此修改仓库内容。若以后需要多人在线管理或限制访问，可以迁移到带权限控制的内容管理系统。

无人机项目首段为约 2 分 49 秒的蓝色椅子导航与环绕采集实机录像，保留原速，公开副本移除了现场音轨；后续导航视频为 Isaac Lab 仿真节选。其他演示短片从原始素材截取并重新编码，利于快速浏览。原始视频仍保留在上级工作目录，可按具体岗位需要选择更合适的片段。
