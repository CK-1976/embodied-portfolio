# 具身智能项目网站

公开展示采用静态网站，本机编辑台负责保存与自动发布。项目页、内容编辑页和投递版简历共用 `content.json`；图片、视频放在 `assets` 下。编辑页使用实际网页与简历模板实时预览草稿。公开源码中的姓名和邮箱使用占位内容；发布时 GitHub Actions 从私密密钥注入实际资料。公开网站使用完整实机、仿真飞行、仿真数采与灵巧手录像，保留原速和原有声音，工作区原始视频没有改动。

## 本地预览

在本目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

- 项目网站：`http://127.0.0.1:8000/`
- 内容编辑：`http://127.0.0.1:8000/editor.html`
- 投递版预览：`http://127.0.0.1:8000/resume.html`

不要直接双击 HTML 文件；浏览器对本地 JSON 文件有限制。

## 一键更新网页和 PDF

首次在常用电脑运行 `./安装本机发布服务.sh`。它为当前用户安装 `portfolio-publisher.service`，服务随登录启动，只监听 `127.0.0.1:8771`，沿用已有的 Git / GitHub CLI 登录。个人资料保存在仓库上级目录的 `portfolio-private-profile.json`，不能放进公开仓库。

之后直接打开[在线编辑页](https://ck-1976.github.io/embodied-portfolio/editor.html)：

1. 修改文字或选择、拖入图片及 MP4 视频，右侧查看实际网页和简历预览。自动保存的是浏览器草稿，页面会提示“有未发布修改”。
2. 点击顶部固定的 **一键更新**，或正文的 **一键更新网页和 PDF**。
3. 页面自动打开本机发布窗口，把当前草稿与新增素材传入；无需导出、复制文件或重新编辑。保持发布窗口打开，状态会回传到在线编辑页。
4. 本机保存内容和素材、同步个人资料密钥并推送 GitHub；Actions 生成 PDF、发布 Pages。核对线上内容与 PDF 后才显示“已发布”。

这个流程需要在已安装本机服务的电脑上使用；浏览器若拦截发布弹窗，请允许后重试。服务尚未启动、版本冲突、上传失败或发布失败都会显示具体提示，草稿仍保留。首次安装后不需要每次手动启动终端。也可直接打开 `http://127.0.0.1:8771/editor.html` 编辑发布，或运行 `./启动编辑台.sh` 打开已有服务。

在线页与本机窗口通过随机会话编号、准确的来源和窗口校验传递草稿；发布接口仍只接受本机同源临时令牌。GitHub 凭据不会进入网页代码、浏览器存储或窗口消息。公开源码中的个人信息保持占位内容，发布时才注入实际姓名和联系方式，提交使用通用维护者身份。

草稿记录来源版本。网站内容更新后，旧草稿会先备份；可点击“恢复已备份草稿”查看。“载入最新内容”可主动刷新。过期窗口不能覆盖新版本；发布失败后，本机已接受的内容会记录重试基线，刷新后仍可继续编辑并再次一键发布。本机每次保存前的备份放在仓库外 `portfolio-editor-backups`。

**导入与备份** 菜单保留 JSON 导入、内容下载、私密资料复制、本地目录保存及发布包下载。导出的公开内容不包含真实姓名、缩写、邮箱和电话。清除浏览器网站数据会丢失尚未发布的草稿和新增素材，请及时发布或备份。

查看本机服务状态：`systemctl --user status portfolio-publisher.service`。停止并取消登录启动：`systemctl --user disable --now portfolio-publisher.service`。

需要手动生成带个人资料的 PDF 时，先复制前端文件到 Git 忽略的 `_site`，执行 `python3 prepare_site.py --site _site --profile-file /仓库外路径/private-profile.json` 和 `python3 build_pdf.py --site _site`。这需要 Chrome 或 Chromium。PDF 包含当前勾选“纳入 PDF 简历”的项目；生成文件不能提交到公开仓库。

## 通过 GitHub Pages 发布

公开源码仓库为 [CK-1976/embodied-portfolio](https://github.com/CK-1976/embodied-portfolio)，面试官访问[项目网站](https://ck-1976.github.io/embodied-portfolio/)即可。仓库的 GitHub Actions 工作流会在推送 `main` 分支后注入私密资料、生成最新 PDF 并发布网站。若密钥缺失或 PDF 生成失败，工作流会停止发布，避免网页与简历内容不一致。源码仓库及 Git 历史不包含姓名和邮箱；网页和 PDF 仍公开展示这些信息。

发布前请逐项确认个人资料、公司项目描述和媒体内容；GitHub Pages 页面是公开网页。`editor.html` 的草稿只保存在访问者自己的浏览器，访问者不能借此修改仓库内容。若以后需要多人在线管理或限制访问，可以迁移到带权限控制的内容管理系统。

所有项目视频均播放完整内容，不再使用 22～25 秒的节选。无人机实机录像约 2 分 49 秒，实机控制网页中的导航环绕约 2 分 39 秒，左侧箱子约 1 分 35 秒，右侧箱子约 1 分 9 秒，黑色手提箱约 55 秒，灵巧手使用最新修改的 1、2、3 三段视频顺序拼接约 24.7 秒，各段均保留全长。保留视频原速与原有音轨；H.264 原片直接封装以保留画质，灵巧手混合素材统一为 H.264 竖屏画布后拼接，保留原速与完整画面。网页媒体地址使用独立的完整版本名称，避免浏览器继续命中旧节选缓存。发布副本独立保存在 `assets/video`，本机原始素材后续移动不会影响网站播放。

无人机实物照片按正面、俯视图、背面展示。“导航并环绕”、左右侧箱子和黑色手提箱视频均为实机控制网页录屏，归入实机演示；飞向红车 / 飞向白车为仿真飞行，数采一 / 二为仿真数采。
