# 具身智能项目网站

公开展示采用静态网站，本机编辑台负责保存与自动发布。项目页、内容编辑页和投递版简历共用 `content.json`；图片、视频放在 `assets` 下。编辑页使用实际网页与简历模板实时预览草稿。公开源码中的姓名和邮箱使用占位内容；发布时 GitHub Actions 从私密密钥注入实际资料。公开网站包含实机录像、完整仿真飞行与数采录像及演示节选，工作区原始视频没有改动。

## 本地预览

在本目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

- 项目网站：`http://127.0.0.1:8000/`
- 内容编辑：`http://127.0.0.1:8000/editor.html`
- 投递版预览：`http://127.0.0.1:8000/resume.html`

不要直接双击 HTML 文件；浏览器对本地 JSON 文件有限制。

## 编辑后自动发布

在本机运行 `./启动编辑台.sh`，打开 `http://127.0.0.1:8771/editor.html`。本机需要已登录的 GitHub CLI（`gh auth login`）以及仓库推送权限，个人资料保存在仓库上级目录的 `portfolio-private-profile.json`，不能放进公开仓库。

1. 左侧选择首页、经历、能力或项目，右侧查看实际网页与简历模板。网站字段与 PDF 字段会标明各自显示位置；同一字段只保存一份。
2. 选择或拖入图片、MP4 视频。单个文件不超过 80 MB。可填写“素材分组”，例如“仿真飞行”“仿真数采”，网页按组显示。
3. 点击 **保存并发布**。编辑台检查内容、保存新增素材、单独更新个人资料密钥并推送 GitHub；GitHub Actions 自动生成 PDF 并发布 Pages。页面显示构建进度，核对线上内容与 PDF 后才显示“已发布”。整个过程通常需要几分钟，请保持本机编辑服务运行。
4. 正式网页在重新打开、切回窗口或每分钟检查时读取最新内容。编辑台实时预览的是当前草稿；正式网页及投递 PDF 在发布成功后更新。

自动保存到浏览器的草稿并未公开。每份草稿记录其来源版本；网站内容更新后，编辑器载入最新版并备份旧草稿，不再一直显示陈旧内容。“恢复已备份草稿”可找回上一次备份，“载入最新内容”可主动刷新。保存冲突时会提示先载入最新版。发布失败会保留本机文件和草稿，可检查后重试；每次发布前的内容与个人资料备份放在仓库外的 `portfolio-editor-backups`。

本机服务只监听 `127.0.0.1`，保存接口需要同源校验和临时令牌。它沿用本机 Git / GitHub CLI 登录，浏览器不保存 GitHub 访问令牌。提交使用通用维护者身份；真实姓名和联系方式从内容中分离，只通过 GitHub Actions 密钥注入公开网页和 PDF。

[公开编辑页](https://ck-1976.github.io/embodied-portfolio/editor.html)可以预览、导入和备份草稿；GitHub Pages 不能接收写入，因此自动发布需打开本机编辑台。在线草稿不会自动跨域转入本机：如有需要，先导出内容和新增素材，再在本机导入或重新选择文件。任意设备在线发布需要另配身份验证服务。

“保存到本地项目目录”“下载发布包”“仅下载内容 JSON”作为备份和手动发布方式保留。导出的公开内容不包含真实姓名、缩写、邮箱和电话；点击“复制私密资料”可单独备份个人资料，不要提交到仓库。清除浏览器网站数据会丢失尚未发布的草稿和素材，请及时保存。

需要手动生成带个人资料的 PDF 时，先复制前端文件到 Git 忽略的 `_site`，执行 `python3 prepare_site.py --site _site --profile-file /仓库外路径/private-profile.json` 和 `python3 build_pdf.py --site _site`。这需要 Chrome 或 Chromium。PDF 包含当前勾选“纳入 PDF 简历”的项目；生成文件不能提交到公开仓库。

## 通过 GitHub Pages 发布

公开源码仓库为 [CK-1976/embodied-portfolio](https://github.com/CK-1976/embodied-portfolio)，面试官访问[项目网站](https://ck-1976.github.io/embodied-portfolio/)即可。仓库的 GitHub Actions 工作流会在推送 `main` 分支后注入私密资料、生成最新 PDF 并发布网站。若密钥缺失或 PDF 生成失败，工作流会停止发布，避免网页与简历内容不一致。源码仓库及 Git 历史不包含姓名和邮箱；网页和 PDF 仍公开展示这些信息。

发布前请逐项确认个人资料、公司项目描述和媒体内容；GitHub Pages 页面是公开网页。`editor.html` 的草稿只保存在访问者自己的浏览器，访问者不能借此修改仓库内容。若以后需要多人在线管理或限制访问，可以迁移到带权限控制的内容管理系统。

无人机项目首段为约 2 分 49 秒的蓝色椅子导航与环绕采集实机录像，保留原速，公开副本移除了现场音轨；仿真飞行新增 raw2red、raw2white 两段完整原速录像，仿真数采新增两段约 73 秒的完整录像。四段新增视频保留画质和时长，公开副本移除音轨；较早的其他演示短片为节选。原始视频仍保留在上级工作目录，可按具体岗位需要选择更合适的片段。
